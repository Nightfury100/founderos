# 3-minute screen-recording script

Audience: Henrik Jonsson (CEO). Message: "your published material, made
conversational — and it never makes anything up."

**Prerequisite:** run this ONLY after real acquisition
(`npm run acquire && npm run parse && npm run brand && npm run label`) — the
fixture banner must be gone. Have the app open at Demo 1, browser at 125% zoom,
nothing else on screen.

## 0:00–0:20 — The contrast (Demo 1, "ScanBox today" toggle)
- Start on the **ScanBox today** view. Click two facets (e.g. *Compressor
  cooling* + *GN 2/1*).
- Say: "This is your buying journey today — the buyer must already know what
  fan heating and GN 2/1 mean. Watch what happens when they don't." Click a
  third facet to show a thin or empty result.

## 0:20–1:10 — Needs Advisor (Demo 1, "With AI")
- Toggle to **With AI**. Type:
  `220-bed care home, meals cooked centrally, two service lifts, lunch at 12:00, some diabetic and pureed diets`
- If it asks clarifying questions (max 3), answer one, press again.
- Point at: the recommended units, the **quantity arithmetic** ("220 covers /
  documented capacity"), and the **source panel** — every unit links to its
  real product page. Add one unit to **My quote** (mirrors their own pattern).
- Say: "Every value on this screen is looked up from your published specs.
  Nothing is generated."

## 1:10–1:50 — Spare Parts (Demo 2)
- Open **Spare Parts**. Point at the **Sample input** badge: "we don't
  pretend this is a customer photo."
- Click **Identify unit**. Point at: extracted fields, the matched unit, the
  manual link, and the **pre-filled order request** addressed to
  spareparts@scanbox.se.
- Say: "Today this is a phone call between 8 and 4. This is the same request,
  ready at 11pm on a Sunday." If parts data was not found in the manuals,
  point at the limitation banner: "and where your documentation stops, the
  demo says so instead of inventing part numbers."

## 1:50–2:25 — Tender Generator (Demo 3)
- Open **Tender Generator**. Pick a unit, switch language to **Deutsch**,
  click **Generate**.
- Point at the fields panel: "each value traced to the exact source field —
  and look, a missing value literally says *nicht angegeben* rather than a
  plausible number." Click **Export .docx**.

## 2:25–3:00 — Support Assistant + the refusal (Demo 4)
- Ask: `how do I replace the gasket on an Ergo Line?` — point at the citation
  chips (manual + page number), click one to open the PDF.
- Then ask the trap: `how many did FC Schalke buy?`
- Read the refusal aloud: "This isn't in ScanBox's published material… contact
  support." Close: "That refusal is the whole pitch. An assistant your brand
  can trust, because it only speaks from your own documentation."
